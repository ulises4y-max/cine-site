Política de privacidad

Última actualización: 16 de octubre de 2026.

Esta política describe cómo funciona CINE actualmente. CINE se ejecuta en el equipo del usuario; este sitio es solo informativo.

Importante: el texto transcrito de tus videos sí se envía a un tercero (Google) para traducirlo. Si no quieres eso, no uses la traducción con Gemini.

Qué se procesa localmente

  • El video original se lee en el equipo del usuario. El audio se transcribe localmente con Whisper y FFmpeg; CINE no envía el audio ni el video a ningún servicio.
  • La primera vez, Whisper descarga su modelo desde internet.
  • La salida (SRT, JSON y, si se pidió, el MP4 subtitulado) se guarda en las carpetas configuradas por CINE, por defecto dentro de la carpeta de datos del programa.

Qué se envía a Google (Gemini)

  • Para traducir y ajustar subtítulos, CINE envía a la API de Gemini el texto transcrito de los diálogos, sus tiempos, algunos fragmentos previos como contexto y el idioma detectado.
  • El tratamiento que Google da a esos datos se rige por las condiciones y políticas de Google para la API de Gemini y por el plan de la clave que use cada usuario. No podemos verificar sus prácticas de retención y aquí no hacemos afirmaciones sobre ellas. Consulta las políticas de Google.
  • CINE no envía el archivo de video ni el de audio.

Claves y credenciales

  • Las claves API (por ejemplo GEMINI_API_KEY) deben mantenerse en variables de entorno, no en el código.
  • CINE no guarda las claves en los archivos de trabajos ni en los registros.
  • Si el usuario habilitara la integración con TikTok, la autorización se haría con el inicio de sesión oficial de TikTok y el token se guardaría cifrado con Windows. Esa integración está desactivada.

Datos guardados localmente

  • Trabajos de procesamiento: ruta y nombre del video original, duración, texto original y traducido con sus tiempos, resultados de cada etapa, estados, errores y fechas.
  • Registros (cine.log): eventos de las etapas, estados y mensajes de error. Pueden incluir nombres de archivo y rutas, y el texto de error que devuelva la API de Gemini.
  • Cola de publicación: título, descripción, declaración de derechos y estado de cada video preparado.
  • Estos datos permanecen en el equipo hasta que el usuario los borre. Si la carpeta está dentro de un servicio de sincronización (por ejemplo OneDrive), ese servicio podrá sincronizarlos según su propia configuración.

TikTok

La publicación en TikTok es experimental y está desactivada. Actualmente CINE no se conecta a TikTok ni transmite datos a TikTok.

Este sitio

Este sitio es estático. No usa cookies, analítica, rastreadores ni publicidad por parte nuestra. Si se aloja en un servicio como GitHub Pages, ese servicio puede registrar visitas según sus propias políticas.

Derechos y contacto

Los datos de CINE están en el equipo del usuario, quien puede consultarlos o borrarlos directamente. Para preguntas, consulta la página de soporte.
